Notes / action items

Scope

  1. Platforms in scope: Web iOS Android
    Mobile stack: React Native Native Flutter Other
  2. Approximately how many pages / screens?
  3. What are your 3–5 most critical user journeys (e.g., sign-up, login, checkout, payments, account settings)?
  4. Do you have a sitemap.xml we can use for discovery?
  5. Anything out of scope (third-party widgets, embedded payments, PDFs, video, marketing site)?

Access & environments

  1. Is the portal behind a login? Can you provide test accounts for each user role?
  2. Is a staging / QA environment available for testing?
  3. Will bot protection, CAPTCHA, MFA, or rate limiting block automated scans? Can our IP be allowlisted?
  4. Can we get read access to the code repository? Which frontend framework do you use?
  5. Which issue tracker do you use (e.g., Jira)? Can we file tickets directly?

Deliverables & next steps

  1. Who is the audience for the report (executive, legal, engineering, procurement)?
  2. Interested in remediation support or ongoing monitoring beyond the assessment?
  3. Who is the primary contact, and how should critical findings be shared?

What to expect: Our assessment combines automated scanning (axe, Lighthouse) with manual keyboard and screen-reader testing, because automated tools catch only about a third of WCAG issues. You'll receive prioritized findings mapped to WCAG success criteria, an executive summary, and remediation estimates. A typical medium-size web assessment takes 20–35 hours.
