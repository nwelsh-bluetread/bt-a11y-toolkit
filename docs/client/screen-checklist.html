Shared components (flagged on many screens)

Only fail a screen for one of these if you actually see or hear the problem on that screen. Name the component in the issue, e.g. side menu close button has no name (Menu).

How it works

  • Pick a screen on the left and work down its checks. Each group's Setup line tells you which device setting to use.
  • Mark each check Pass, Fail, or N/A. Click the active button again to clear it.
  • On a fail, describe each problem and pick a severity. The first issue goes on the check's line; the rest go on indented lines below it.
  • ⚑ High/Medium: the code scan found this in this screen's own code. ⚑ Verify: the scan can't judge it, so check by hand. Pass or fail is still your call.
  • A screen passes when every check is Pass or N/A, and fails if any check fails or it has an Other issue.
  • When you're done, run node a11y-audit/screen-checklist.mjs apply to copy results into checklist.md.

Keyboard

  • P Pass and N N/A, then move to the next check
  • F Fail and jump to the issue field. Enter goes to the next check, Esc back to the buttons
  • U clear the mark
  • J / K next / previous check
  • ] / [ next / previous screen

Saving

Chrome and Edge write to the .md file as you go. If the file changes on disk while it's open here (for example, you edit it in VS Code), saving stops and asks what to do. In other browsers, your work stays in this browser until you download it.
